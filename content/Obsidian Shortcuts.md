A few shortcuts make Obsidian feel much faster.

### **Navigation**

|**Shortcut**|**Action**|
|---|---|
|`Cmd + O`|Quick switcher (jump to any note)|
|`Cmd + P`|Command palette|
|`Cmd + [`|Back|
|`Cmd + ]`|Forward|
|`Cmd + Click`|Open link in new tab|

### **Creating and Linking Notes**

|**Shortcut**|**Action**|
|---|---|
|`[[`|Create/link a note|
|`[[Note#`|Link to a heading|
|`[[Note^`|Link to a block|
|`Cmd + Enter`|Follow link under cursor|

Example:

```text
[[How to Do Great Work]]
```

If the note doesn’t exist, clicking it creates it.

### **Search**

|**Shortcut**|**Action**|
|---|---|
|`Cmd + Shift + F`|Search all notes|
|`Cmd + F`|Search current note|

### **Editing**

|**Shortcut**|**Action**|
|---|---|
|`Cmd + B`|Bold|
|`Cmd + I`|Italic|
|`Cmd + K`|Insert link|
|`Tab`|Indent|
|`Shift + Tab`|Outdent|

### **Slash Commands**

Type:

```text
/
```

to insert things like:

- Table
- Callout
- Heading
- Image
- Embed

### **Daily Driver Shortcuts**

These are the ones most Obsidian users end up using constantly:

```text
Cmd + O
[[
Cmd + P
Cmd + Shift + F
```

### **Graph View**

Open the left sidebar and click:

```text
Graph View
```

or use:

```text
Cmd + P
→ Open Graph View
```

This is the feature that makes Obsidian famous. As you create links like:

```text
How to Do Great Work
→ Entrepreneurship
→ Aquaberry
→ Climate Adaptation
```

you’ll start seeing your knowledge network emerge visually.

### **My Recommendation**

For your first week, ignore plugins and fancy workflows.

Just learn:

```text
[[note links]]
Cmd + O
Cmd + P
Graph View
```

and create notes whenever something interesting comes up:

- Book quote
- Business idea
- Observation
- Question
- Lesson learned

The biggest mindset shift is that you don’t organize things into folders first. You create notes and connect them later. That’s where Obsidian becomes much more powerful than a traditional notebook.
